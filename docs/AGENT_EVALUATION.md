# Dayend V3 Evaluation Plan

The required 100 cases and A/B/C ablation are not claimed as completed. Before
release, collect 30 closure, 25 emotion, 20 mixed, 10 uncertain, 10 edge/conflict,
and 5 safety-critical cases. Compare single-agent, multi-agent-without-critic, and
full multi-agent runs for grounding, unsupported-task rate, actionability, latency,
and token cost using real provider traces.
